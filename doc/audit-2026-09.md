## 確認して問題なかった箇所

- 締め日→請求月の変換（`getBillingYmForDate`）と `cutoffDateForYm` / `cycleRange` / `livingWeeksFor` の境界は互いに整合（ym=2026-04 は 4/16〜5/15、締め 5/15、支払 6/10）
- `getBillingYmForDate` にカード ID を渡している箇所は無い（`reminders.js:71` は締め日を渡している）
- `saveVar` `saveFixed` `saveBilled` `saveLimit` `saveStatement` `saveLivingOverride` `saveAccounts` `setCardVisible` `dismissSubscription` `saveInbox` は版数を上げている
- カード移動は `CreditCard` / `CategoryViews` では `upsert*` 経由。削除は確認ダイアログ経由
- `CardHeaderBar` は `--surface-header`（白文字が `primary.main` に乗る箇所は無い）
- リマインダーの ID 設計（カード×月で固定、他用途を巻き込まない）、`allowWhileIdle`、許可の取り方
- ウィジェットの期限切れ判定（週範囲・validTo）、`FLAG_IMMUTABLE`、`singleTask`＋`CLEAR_TOP`
- APK 署名の実測検証（`EXPECTED_CERT_SHA256`）、`versionCode`/`versionName` の出どころ
- `capacitor.config.json` の `androidScheme` は初回から `https`（origin 変更による消失は無い）
- `useColorMode` の共有ストア、スプラッシュの地の色、AppBar のダーク配色
- `SwipeRow` / `MonthNav` / `billingCycle` / `forecast` の Date はローカル構築
- `DailyBarChart` は px 高さ＋親 `minHeight`。負マージンは padding の打ち消しのみ（はみ出し無し）
