# 資産管理アプリ

スマートフォンで使える、個人向けのお金の管理アプリです。
給与の手取り計算・クレジットカードの支出管理・家計の予実管理をまとめて行えます。

完全オフラインで動作し、データは端末のブラウザ内にのみ保存されます。

---

## 画面構成

4 つのタブで構成されています。

### クレカタブ

JCB と VISA の支出をカードごと・月単位で管理します。

- 固定費・変動費の登録・編集・削除
- 使用額と月間上限の進捗、締め日・支払日までの残り日数
- 予算内訳：上限額から固定費・生活費・その他変動費を差し引いた残高を予定/実績で表示
- 日別支出グラフ
- 消費分類（消費・投資・浪費）グラフ ※変動費のみが対象
- カテゴリ別グラフ・集計（カテゴリごとの月間予算も設定可能）
- 年間サマリー（12 ヶ月の推移）

### 家計タブ

月の収支全体を俯瞰します。

- 2 枚合計の使用額サマリー
- 給与（手取り）の入力と、固定費・カード使用額の予定/実績比較
- 生活費カード（週予算の進捗・週履歴・サイクル）
- 支出トレンド（6 ヶ月の推移）
- 消費分類・カテゴリ別グラフ・集計

### 支出一覧タブ

固定費・変動費をまとめて 1 つの明細として時系列で見ます。

- カード・カテゴリを横断した月の支出明細
- 項目別・支払元別の集計

### 給与タブ

残業時間を入力するだけで、その月の手取り金額をリアルタイム計算します。

- 職能給・各種手当・社会保険料を自由に編集
- 雇用保険・所得税は実際の明細に合わせた計算式を採用
- 支給・控除のカスタム項目を追加可能

## 支出の操作方法

固定費・変動費のリストは iOS のリストと同じ作法です。

| 操作 | 動作 |
|------|------|
| 行をタップ | 編集ダイアログを開く |
| 左へスワイプ | 削除ボタンを表示（速く弾くとそのまま削除確認へ） |
| 行頭のチェック | 引き落とし済みにする（固定費のみ） |
| 右下の ＋ | 支出を追加（電卓で金額入力） |
| 長押し | 編集・削除メニュー（変動費のみ） |

編集ダイアログでは支払い方法（カード）も変更できます。カードごとに締め日が
違うため、変更すると請求月を計算し直して正しい月へ移動します。

## 設定

右上の歯車アイコンから変更できます。

| 設定項目 | 内容 |
|---------|------|
| 給与設定 | 基本給・手当・控除項目の編集 |
| カード設定 | 保有カード・締め日・支払い日・上限額 |
| 給与履歴 | 過去明細の確認・推移グラフ（給与明細 PDF の取り込みに対応） |
| データ管理 | データのエクスポート・インポート |
| 外観 | テーマ切替（Apple 風 / 現行） |
| アプリ情報 | バージョン等 |

---

## データについて

入力したデータはすべて **お使いのスマートフォン・PC のブラウザ内にのみ保存** されます。
外部サーバーやクラウドへの送信は一切ありません。

ブラウザのデータを削除すると設定も消えます。設定 → データ管理 から
エクスポートできるので、定期的なバックアップを推奨します。

## 起動方法

**Node.js** が必要です。

```bash
npm install    # 初回のみ
npm run dev    # 開発サーバー起動
```

起動後、ブラウザで `http://localhost:5173` を開いてください。

```bash
npm run build    # 本番ビルド
npm run preview  # ビルド結果の確認（http://localhost:4173/my_forward/）
npm run lint     # ESLint
npm test         # Vitest
```

`main` ブランチへの push で GitHub Pages へ自動デプロイされます
（`.github/workflows/deploy.yml`）。公開パスは `/my_forward/` です。
